\begin{frame}{Limitations}
  \begin{itemize}
    \item \textbf{Synthetic benchmark}: Juliet units are small and single-file; real leaks span files and ownership
    \item \textbf{Leak definition} includes memory reachable from globals at exit and \code{realloc} failure paths
    \item \textbf{Weak checkpoint selection}: dev AUROC is saturated, so dev cannot pick the robust LoRA checkpoint
    \item \textbf{Budget}: DeepSeek runs on the nested25 subset (664 units) for layer \ding{174}, placebo and original
    \item \textbf{Thresholds are descriptive}: macro-F1 with bootstrap CIs, no tuned cut-offs claimed as deployable
    \item \textbf{Contamination}: Juliet is public; layer \ding{174} is new, which is why it is the key test
  \end{itemize}
\end{frame}
