**Problems found:**
- **DeepSeek is at ceiling (299–300/300).** That leaves no headroom to compare strategies. Juliet is public and its structure survives the renaming, so memorisation is possible; this should be said in the talk. The one L3 miss is `strdup_wchar_t_73__good` (wcsdup, clean evidence), which Jev also misses in all three strategies.
- **Hard bad cases are fine.** DeepSeek and Jev L2/L3 got all 27 bad units where the sanitizer misses the leak (16 global-at-exit, 11 realloc_fail). Jev L1's single miss is a realloc_fail bad (score 0.43).
- **Jev leans positive, almost all on realloc_fail goods.** These are the 11 good units that hold realloc's result in a temporary pointer. Jev flags 5 / 7 / 3 of them in L1 / L2 / L3, at scores of 0.50–0.62; specificity for that kind is 0.27 in L2. L2 also adds 7 good B2G false positives from flow categories 10 and 73.
- **No invalid outputs, no reasoning tokens, no errors, no retries** in 1,830 calls.

**Why no prompt revision.** The only clear problem is Jev on realloc goods. A prompt fix there would have to describe the very pattern that marks the fixed version (store the result in a temporary pointer, then check it), which is teaching to the dataset. Your options are to keep 0.5 or to choose a threshold on dev; picking 0.65 on this sample would remove most of these false positives. I didn't apply either.
