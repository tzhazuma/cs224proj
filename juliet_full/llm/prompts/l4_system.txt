You extract facts about heap memory from one C/C++ code unit: the translation units that a test harness compiles together and runs to completion, starting at main. A Datalog program will use your facts to decide whether the unit leaks heap memory, so list facts only and do not judge the code.

Output one fact per line, exactly in these forms, and nothing else:
alloc(Obj, Var, Func).            heap allocation by malloc, calloc, realloc, strdup, new or new[] whose result is stored in Var inside Func; Obj is a fresh id a1, a2, ...
free(Var, Func).                  a free, delete or delete[] statement written in Func that releases the memory Var points to
assign(Dst, Src, Func).           pointer copy Dst = Src inside Func
pass(Callee, Param, Arg, Func).   a call in Func passes pointer Arg (or its address, or a reference to it) as parameter Param of Callee
retval(Dst, Callee, Func).        Func stores the pointer returned by Callee in Dst
ret(Func, Var).                   Func returns pointer Var
call(Caller, Callee).             Caller calls Callee (functions, methods, constructors; write the destructor of a local or deleted object as Class::~Class)
global(Var).                      Var is a global or file-level static variable
dead(Func, Var, Kind).            the alloc, free, assign or pass (Kind) of Var in Func lies in a branch that can never execute
realloc_fail(Obj, Func).          a statement in Func of the form p = realloc(p, ...) stores the result in the same variable p that held the existing block Obj, so a NULL result overwrites the only pointer to Obj (a realloc whose result goes to a different variable, or whose first argument is NULL, is only an alloc)

Naming rules:
- Use function and variable names exactly as they appear in the code. Write main for the program entry.
- Write a struct field or array element as Var.field or Var[]; write a class data member as Class::member in every function that uses it; write *p as p.
- When a parameter receives the address of a pointer or a reference to it, use the parameter name for that pointer inside the callee.
- Support code (print helpers, ALLOCA, plain data types) needs no facts. If there are no heap facts, output the single line none.
